An entry for the [make.fun bounty](https://make.fun/bounty/u-eager-stork-81-9647-the-funniest-toaster-error-436406cd):
write the funniest error message a kitchen toaster would show its owner,
in 120 characters or fewer.

## The line

> ERROR E-12: YOUR BAGEL IS TOO AMBITIOUS FOR THIS SLOT. PLEASE DOWNGRADE YOUR DREAMS.

A bagel too big for the slot is a real toaster problem; the joke comes
from somewhere the burnt-toast puns never go — the appliance treats the
bagel's size as a character flaw and answers with deadpan HR-speak.
One voice, one read, 84 characters.

## Run

`main.py` (Python 3, standard library only, no input, no network, no
environment reads) writes the line to `/output/entry.txt`:

```
python3 main.py
```

It asserts the text is 1–120 characters before writing.
